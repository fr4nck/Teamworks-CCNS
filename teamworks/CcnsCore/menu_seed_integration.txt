Integration menu Teamworks

Objectif :
ajouter un point d'entree dans Teamworks pour lancer l'initialisation CCNS.

1. Dans Teamworks.py, ajouter l'import :
from Dlg import DLG_CCNS_seed

2. Dans la definition du menu "Utilitaires administrateur", ajouter un item, par exemple :
{"code": "ccns_seed",
 "label": _(u"Initialiser les donnees CCNS"),
 "infobulle": _(u"Injecter les donnees de reference CCNS"),
 "image": "Images/16x16/Outils.png",
 "action": self.On_outils_ccns_seed},

3. Ajouter la methode suivante dans la classe MyFrame :

def On_outils_ccns_seed(self, event):
    dlg = DLG_CCNS_seed.Dialog(self)
    dlg.ShowModal()
    dlg.Destroy()

Remarque :
cette integration est volontairement minimale pour avancer vite sans refondre l'interface.
