# Gadgets d'accueil CCNS

Cette étape ajoute le sujet qui manquait : les gadgets d'accueil CCNS.

## Fichiers ajoutés

- `teamworks/CcnsCore/home_gadgets_ccns.py`
- `teamworks/Ctrl/CTRL_Gadget_CCNS.py`
- `teamworks/Dlg/DLG_Accueil_ccns_integration.txt`

## Ce que ça apporte

Un gadget d'accueil compact avec :
- nombre de contrats audités ;
- anomalies CCNS détectées ;
- contrats bloquants ;
- contrats à revoir ;
- individus avec alertes ;
- individus avec blocages ;
- liste courte des alertes prioritaires ;
- ouverture directe du contrat.

## Positionnement

Ce n'est pas un registre ni un écran complet.
C'est un tableau d'appel rapide à placer sur l'accueil.
