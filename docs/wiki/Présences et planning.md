# Présences et planning

Les fonctions de présence permettent d'enregistrer et consulter l'activité des personnes suivies dans Teamworks-CCNS.

## Fonctions principales

Selon les modules utilisés :

- consultation des présences ;
- saisie ou modification ;
- navigation par période ;
- calendriers ;
- contrôles associés aux personnes et contrats.

## Attention

Les règles métier liées :

- au temps de travail ;
- aux récupérations ;
- aux repos ;
- aux CEE ;
- aux contraintes CCNS ;

évoluent encore dans Teamworks-CCNS.

Une distinction doit toujours être faite entre :

- les données saisies ;
- les contrôles actuellement implémentés ;
- les obligations légales ou conventionnelles.

Le logiciel ne doit pas être considéré comme un substitut aux textes applicables.
