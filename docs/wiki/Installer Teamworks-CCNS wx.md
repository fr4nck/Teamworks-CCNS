# Installer Teamworks-CCNS wx

Cette page concerne la version **Vanilla wx** de Teamworks-CCNS.

## Windows

Les versions distribuées peuvent être proposées sous deux formes :

- **installateur Windows** : recommandé pour une utilisation normale ;
- **archive portable** : utile notamment pour les tests et diagnostics.

Utiliser uniquement les paquets publiés par le projet Teamworks-CCNS.

## Vérifier la version installée

La version de l'application est disponible dans l'application et dans le fichier `VERSION` du paquet.

Les builds de test peuvent également être identifiés par leur commit Git dans `BUILD.txt`.

Exemple :

```text
Teamworks-CCNS 0.9.2-rc3
Commit xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## Mise à jour

Le mécanisme de mise à jour de la Vanilla wx est destiné à utiliser les publications officielles du dépôt Teamworks-CCNS.

Les anciennes sources de mise à jour Teamworks/Noethys ne constituent plus le canal de distribution du fork.

Les versions de test et RC ne doivent pas être confondues avec les versions stables.
