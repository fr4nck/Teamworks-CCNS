# Publipostage et documents

Teamworks-CCNS permet de générer différents documents à partir des données enregistrées.

## Publipostage

Le publipostage peut être utilisé notamment depuis :

- les individus ;
- les contrats ;
- différentes listes de données.

## Suites bureautiques

Les parcours historiques utilisent principalement :

- Microsoft Word ;
- LibreOffice Writer.

Le comportement peut varier selon la suite installée et sa version.

## Modèles

Les modèles peuvent utiliser des champs issus des données Teamworks.

Certaines compatibilités historiques sont conservées lorsque cela est nécessaire.

## En cas de problème

Pour un crash ou un blocage :

1. noter la version Teamworks-CCNS ;
2. noter la suite bureautique utilisée ;
3. conserver le rapport de crash ;
4. indiquer si le problème apparaît dès le premier publipostage ou après plusieurs utilisations.
