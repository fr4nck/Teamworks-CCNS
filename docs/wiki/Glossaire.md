# Glossaire

| Terme | Définition dans Teamworks-CCNS |
|---|---|
| **Individu** | terme d’interface pour une personne suivie dans le dossier principal |
| **Personne** | objet de données correspondant à l’Individu ; ce nom apparaît notamment dans le code et le contexte de publipostage |
| **Candidat** | personne encore suivie dans le module Recrutement avant conversion éventuelle en Individu |
| **Candidature** | dossier de recrutement lié à un candidat ou, après conversion, à une personne |
| **Contrat** | engagement rattaché à une personne, avec type, dates, durée, rémunération et données CCNS/CEE selon le cas |
| **CEE** | contrat d’engagement éducatif ; Teamworks possède des champs/barèmes spécifiques, à distinguer d’un contrôle juridique complet |
| **CCNS** | Convention collective nationale du sport ; le moteur calcule certains minima et contrôles de rémunération à partir des données disponibles |
| **DPAE / DUE** | module historique d’édition du formulaire d’embauche ; l’édition PDF ne prouve pas une télétransmission officielle |
| **Teamword** | éditeur RichText intégré de Teamworks, utilisé aussi pour les modèles `.twd` et l’email HTML |
| **Publipostage** | fusion d’un modèle avec les données d’un ou plusieurs éléments/personnes |
| **Mot-clé** | balise de modèle sous la forme `{MOTCLE}` remplacée par une valeur du contexte |
| **Champ personnalisé** | donnée dont le nom est défini dans le dossier et qui peut rejoindre le publipostage selon sa configuration |
| **Dossier local** | dossier stocké dans les fichiers de données locaux, notamment `<nom>_TDATA.dat` |
| **Dossier réseau** | dossier Teamworks utilisant le mode `[RESEAU]`, généralement adossé à MySQL |
| **MySQL** | moteur de base utilisé par le mode réseau ; distinct du stockage local |
| **RC** | *release candidate*, version candidate à la publication qui nécessite encore qualification |
| **Vanilla wx** | application Teamworks-CCNS basée sur wxPython, rail documenté ici |
| **Qt** | rail de migration séparé ; ses fonctions ne doivent pas être déduites du comportement wx |

## Terminologie recommandée

Le wiki emploie de façon cohérente : **Teamworks-CCNS**, **Vanilla wx**, **Teamword**, **Microsoft Word**, **LibreOffice Writer** (avec mention du libellé historique OpenOffice lorsqu’utile), **Discussions GitHub**, **Issues GitHub** et **Forum historique Teamworks**.
