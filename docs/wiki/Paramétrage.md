# Paramétrage

Le menu **Paramétrage** de Teamworks-CCNS wx regroupe les réglages qui concernent le dossier ou l’application. Certains éléments ne sont activés qu’après ouverture d’un fichier.

## Paramètres d’application mémorisés

L’application conserve notamment :

- le dernier fichier / les fichiers récents ;
- la taille de fenêtre ;
- l’interface MySQL utilisée ;
- des préférences de listes, dont les largeurs/tri des colonnes Individus ;
- pour chaque catégorie de document, le dernier éditeur choisi, le modèle, les options d’impression/sauvegarde/aperçu et les préfixes de fichiers.

## Enregistrement

Le menu contient une entrée **Enregistrement**. Utilisez-la uniquement avec les informations du projet ou de votre déploiement ; le wiki ne reproduit pas d’anciennes procédures/licences historiques non vérifiées.

## Sauvegardes automatiques

Le paramétrage des sauvegardes automatiques est accessible directement depuis le menu **Fichier > Sauvegardes automatiques**. Voir [[Sauvegardes et restauration]].

## Affichage et colonnes

La liste Individus mémorise l’état des colonnes. Si une largeur a été choisie manuellement, le redimensionnement de la fenêtre ne doit plus la remplacer automatiquement. Utilisez les options/réinitialisation de la liste pour revenir aux valeurs par défaut.

## Prudence avec les réglages réseau

La connexion réseau/MySQL et les conversions local/réseau changent la manière dont Teamworks ouvre les données. Sauvegardez d’abord et documentez l’hôte, le port et le nom du dossier avant toute modification. Voir [[Données, sauvegardes et MySQL]].
