# Contrats, CCNS et CEE

Teamworks-CCNS développe progressivement une couche métier commune pour la gestion des contrats et des règles applicables aux équipes.

## Contrats

Le logiciel permet notamment de gérer :

- les contrats associés aux personnes ;
- différentes informations contractuelles ;
- la DPAE/DUE ;
- certains éléments de classification et rémunération ;
- le publipostage lié aux contrats.

## CCNS

Le projet vise à mieux prendre en compte les règles issues de la Convention collective nationale du sport.

Cela comprend progressivement :

- classifications ;
- rémunérations minimales ;
- temps de travail ;
- repos ;
- récupérations ;
- contrôles de planning.

Toutes ces fonctions ne sont pas nécessairement finalisées dans la version actuellement distribuée.

## CEE

Les contrats d'engagement éducatif nécessitent une logique différente de celle des salariés classiques.

Teamworks-CCNS distingue notamment les approches en heures et en jours lorsque cela est nécessaire.

## Règles internes

Une règle interne plus favorable peut être prise en compte lorsqu'elle ne remplace pas une obligation impérative.

Le logiciel doit conserver une distinction entre :

- règle interne ;
- CCNS ;
- autres conventions applicables ;
- obligations impératives ;
- règles propres aux CEE.
