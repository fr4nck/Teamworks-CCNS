# Individus et fiches

La section Individus regroupe les informations concernant les personnes gérées dans Teamworks-CCNS.

## Informations principales

Selon la configuration et les données disponibles, une fiche peut contenir notamment :

- identité ;
- coordonnées ;
- adresse ;
- situation ;
- qualifications ;
- diplômes ;
- pièces ;
- mémo ;
- informations liées aux contrats.

## Liste des individus

La liste permet :

- de rechercher une personne ;
- trier les données ;
- afficher ou masquer certaines colonnes ;
- modifier leur largeur ;
- ouvrir une fiche individuelle ;
- lancer certains exports ou publipostages.

Les préférences de présentation des colonnes peuvent être mémorisées.

## Réinitialiser les colonnes

La configuration de la liste permet de rétablir les réglages d'affichage par défaut si nécessaire.

## Données historiques

Certaines anciennes bases peuvent contenir des références devenues incomplètes.

Teamworks-CCNS cherche à afficher ces situations sans empêcher l'ouverture de la fiche, tout en signalant les références manquantes lorsqu'elles peuvent être identifiées.
