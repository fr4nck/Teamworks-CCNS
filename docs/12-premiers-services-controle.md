# Premiers services de contrôle

Cette étape ajoute les premiers services applicatifs de contrôle.

## But

Préparer les premiers écrans sans fabriquer encore l'interface complète.

## Ce qui est ajouté

- un service de tableau de contrôle global ;
- un service de vue contrat ;
- un service de vue affectation ;
- des modèles simples de données à afficher.

## Ce que ça permet

- compter les anomalies ;
- produire des lignes de tableau de contrôle ;
- préparer une vue contrat ;
- préparer une vue affectation.

## Ce que ça ne fait pas encore

- pas d'écran graphique réel ;
- pas de framework UI ;
- pas encore de filtrage avancé multi-profils.
