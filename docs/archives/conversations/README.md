# Archives récupérées des conversations

Ce dossier contient des sauvegardes datées réalisées avant nettoyage/suppression des conversations du projet.

## Règle d'autorité

- Les **décisions courantes** doivent vivre dans `docs/decisions/`, les issues, les PR, les tests ou le code selon leur nature.
- Les fichiers de ce dossier sont des **archives historiques** : utiles pour retrouver un contexte, mais non prioritaires face à l'état GitHub courant ou à une décision plus récente.
- Toute information d'état (PR ouverte, branche active, mergeabilité, CI, etc.) doit être revérifiée en live.
