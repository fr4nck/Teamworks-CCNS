# Script de démonstration runtime

Cette étape ajoute un premier script de démonstration exécutable.

## But

Montrer que le cœur Teamworks-CCNS peut déjà :
- construire un runtime en mémoire ;
- charger des données de référence ;
- créer une personne ;
- créer un contrat ;
- créer une affectation ;
- lancer plusieurs contrôles ;
- produire des compteurs et des anomalies lisibles.

## Fichier ajouté

- `scripts/demo_runtime.py`

## Ce que le script illustre

- contrat G3 avec salaire inférieur au minimum ;
- contrôle du minimum depuis la grille ;
- contrôle d'ancienneté ;
- vue contrat ;
- vue affectation ;
- tableau de contrôle simplifié.

## Intérêt

C'est le premier point où le dépôt peut être lu comme un embryon réellement exécutable, et plus seulement comme une collection de classes.
