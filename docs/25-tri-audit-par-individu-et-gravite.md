# Tri de l'audit par individu puis gravité

Cette étape adapte l'audit CCNS au besoin de lecture par personne.

## Ce qui change

- tri principal par individu ;
- à l'intérieur de chaque individu :
  - bloquant d'abord ;
  - à revoir ensuite ;
  - OK ensuite ;
- colonne `Gravité` visible dans la liste ;
- résumé comptant aussi le nombre d'individus affichés ;
- export CSV respectant ce tri.

## Pourquoi c'est utile

On garde la logique de gravité, mais sans perdre la lecture humaine par salarié / individu.
C'est plus pertinent pour relire les situations concrètes avant correction.
