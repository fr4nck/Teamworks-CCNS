# Calcul des minima depuis les grilles

Cette étape branche enfin le calcul du minimum théorique à partir :
- d'une grille salariale ;
- de ses lignes ;
- de la classification du contrat ;
- et, si besoin, de l'âge et de l'année d'exécution.

## Ce qui est déjà géré

- minimum mensuel depuis une ligne de grille ;
- minimum annuel depuis une ligne de grille ;
- comparaison au salaire saisi ;
- anomalie si minimum non atteint ;
- anomalie si grille ou ligne applicable absente ;
- sélection d'une ligne plus spécifique selon :
  - l'âge ;
  - l'année d'exécution.

## Ce qui n'est pas encore géré

- majoration diplôme de l'apprentissage ;
- cas détaillés sportifs salariés / entraîneurs ;
- calcul complet de prime d'ancienneté ;
- proratas plus avancés que la simple quotité de travail.

## But

Poser le premier calcul CCNS réellement relié aux grilles du cœur Teamworks.
