# Lot d’intégration interface Teamworks

Ce lot regroupe les points de branchement les plus rentables pour rendre la surcouche CCNS visible dans Teamworks.

## Objectif

Passer de briques préparées à une intégration réellement manipulable dans l’interface existante.

## Périmètre

### 1. Accueil
- ajout du gadget CCNS dans la zone des gadgets existants ;
- vérification du rafraîchissement ;
- ouverture d’un contrat depuis une alerte.

### 2. Dossiers incomplets
- injection des nœuds CCNS sous chaque individu ;
- marquage visuel ;
- double-clic vers contrat ou fiche individuelle.

### 3. Fiche individuelle
- ajout de l’onglet `Synthèse CCNS` ;
- cohérence du statut global ;
- ouverture du contrat depuis la synthèse.

### 4. Audit CCNS
- ouverture depuis le menu ;
- lecture des contrats ;
- filtres ;
- tri ;
- export CSV ;
- ouverture contrat.

## Résultat attendu

Un utilisateur doit pouvoir :
- repérer une alerte depuis l’accueil ;
- retrouver l’individu dans Dossiers incomplets ;
- ouvrir la fiche individuelle et sa synthèse CCNS ;
- relire les contrats via l’audit ;
- ouvrir le contrat concerné.
