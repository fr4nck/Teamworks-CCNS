# Moteur et anomalies

Cette étape ajoute les premiers objets du moteur de contrôle du cœur Teamworks :

- `CalculationRule`
- `CalculationResult`
- `Anomaly`
- `IndividualCounter`

Elle ajoute aussi :
- les premières familles de règles ;
- quelques règles par défaut ;
- deux premiers contrôles simples sur les contrats.

## Ce qui est déjà possible

- créer des règles datées ;
- créer un résultat de calcul ;
- créer une anomalie liée à un résultat ;
- préparer les compteurs individuels ;
- signaler un contrat sans classification ;
- signaler un contrat sans grille.

## Ce qui vient ensuite

- contrôles minima CCNS
- contrôles temps partiel court
- contrôles ancienneté
- contrôles CEE
- contrôles apprentissage
- contrôles mineurs
- écrans de contrôle
