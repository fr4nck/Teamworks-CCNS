# Marquage visuel dans l'audit CCNS

Cette étape ajoute un repérage visuel immédiat dans la liste d'audit.

## Ce qui est ajouté

- lignes rouges pour les cas bloquants / structurels
- lignes jaunes pour les anomalies à revoir
- lignes vertes pour les contrats sans anomalie détectée
- légende affichée dans le dialogue
- compteur de signalements bloquants dans le résumé

## Pourquoi c'est utile

L'utilisateur voit immédiatement :
- ce qui bloque ;
- ce qui mérite relecture ;
- ce qui paraît propre.

## Portée

Le marquage reste simple et robuste, sans dépendre d'un moteur graphique complexe.
