# Canaux de publication

Teamworks-CCNS utilise trois niveaux de version :

- `-dev` : développement courant, non publié comme version stable ;
- `-rc.N` : release candidate destinée aux essais réels ;
- version sans suffixe : version stable validée.

Une release candidate doit être testée sur une copie de base de données avant tout usage courant. Le passage à une version stable exige la validation de la recette correspondante dans `docs/TEST-RELEASE-0.9.0-RC1.md`.
