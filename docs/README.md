## Règle documentaire

Les pages utilisateur expliquent les tâches. Les documents techniques décrivent l'architecture, les décisions et les contraintes.

Quand une page utilisateur doit citer une notion de référence — notamment un mot-clé de publipostage — elle doit pointer vers l'ancre correspondante plutôt que recopier l'information.
