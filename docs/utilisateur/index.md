# Guide utilisateur

Le guide utilisateur est organisé par tâche et non par architecture interne.

## Documents et publipostage

Teamworks dispose d'un éditeur interne, **Teamword**, capable d'insérer les mots-clés disponibles dans un modèle.

Selon le contexte, les mots-clés ne sont pas les mêmes :

- [personne / salarié](../reference/mots-cles-publipostage.md#mots-cles-personne) ;
- [contrat](../reference/mots-cles-publipostage.md#mots-cles-contrat) ;
- [candidat](../reference/mots-cles-publipostage.md#mots-cles-candidat) ;
- [candidature](../reference/mots-cles-publipostage.md#mots-cles-candidature) ;
- [champs personnalisés](../reference/mots-cles-publipostage.md#champs-personnalises).

Voir [Publipostage et modèles](publipostage.md) pour le fonctionnement général.
