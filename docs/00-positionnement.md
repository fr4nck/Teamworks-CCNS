# Positionnement du fork

Ce dépôt est un fork de Teamworks orienté CCNS pour la gestion d’équipes et des cadres d’emploi dans le sport associatif.

L’objectif est d’intégrer progressivement dans Teamworks :
- les contrats ;
- les régimes d’emploi ;
- la classification conventionnelle ;
- les règles de temps de travail ;
- les contrôles métier utiles.
