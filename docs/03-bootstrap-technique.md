# Bootstrap technique du fork Teamworks

## Premier objectif concret
Obtenir une **première base du fork** capable de porter :
- les personnes ;
- les contrats ;
- les classifications ;
- les affectations ;
- les règles ;
- les anomalies.

## Arborescence minimale
- `domain/`
- `application/`
- `infrastructure/`
- `interfaces/`
- `migrations/`
- `tests/`
- `docs/`

## Ordre réel de construction
1. créer le squelette du projet
2. créer `people`
3. créer `legal_profiles`
4. créer `contract_types`
5. créer `employment_regimes`
6. créer `time_organizations`
7. créer `contracts`
