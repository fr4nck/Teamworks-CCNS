# Filtres sur l'audit CCNS

Cette étape rend l'audit CCNS beaucoup plus exploitable en ajoutant des filtres simples.

## Ce qui est ajouté

- anomalies seulement
- filtre par groupe / classification
- filtre par type de contrat
- filtre par salaire minimum
- filtre par salaire maximum
- réinitialisation des filtres

## Pourquoi c'est utile

L'utilisateur peut maintenant :
- isoler rapidement les cas problématiques ;
- cibler un groupe donné ;
- relire seulement les CEE, les apprentis ou les CDI ;
- se concentrer sur une tranche salariale.

## Portée

Le filtrage est volontairement simple et rapide à intégrer, sans refondre la logique d'audit.
