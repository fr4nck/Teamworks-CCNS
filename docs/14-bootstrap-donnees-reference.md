# Bootstrap des données de référence

Cette étape ajoute un petit bootstrap de données de référence pour le cœur Teamworks-CCNS.

## Ce qui est fourni

- classifications CCNS de base :
  - G1 à G8
  - APPRENTI
- une grille salariale de base `CCNS-2026`
- quelques lignes de grille de référence
- les natures de temps par défaut
- les rôles de sécurité par défaut

## Pourquoi c'est utile

Ça permet de :
- lancer les premiers tests métier sans tout saisir à la main ;
- vérifier plus vite les calculs ;
- donner un socle minimum au dépôt.

## Important

Ces valeurs sont un **bootstrap de travail**.
Elles doivent être relues, consolidées et datées proprement si elles deviennent une base de production.
