Teamworks
==================

Fork de Teamworks orienté CCNS pour la gestion d’équipes et des cadres d’emploi dans le sport associatif.
Pour Windows, Mac OS et Linux.

Projet d’origine : https://github.com/Noethys/Teamworks

Ce dépôt vise à faire évoluer Teamworks pour intégrer progressivement les spécificités de la convention collective nationale du sport (CCNS), notamment autour :
- des cadres d’emploi ;
- des contrats ;
- du temps de travail ;
- des contrôles métier.

Télécharger Teamworks
------------------

Cliquez sur le bouton *Code* ci-dessus puis sélectionnez *Download ZIP* pour télécharger l'intégralité du code source. Décompressez ensuite l’archive dans le répertoire de votre choix.

Installer Teamworks sous Linux
------------------

1. Installez Python 3.7 ou plus depuis le site https://www.python.org.

2. Ouvrez votre terminal.

3. Placez-vous dans le répertoire d'installation de Teamworks. Exemple :
```bash
cd Teamworks/
```

4. Installez les dépendances avec la commande suivante :
```bash
pip install -r requirements.txt
```

Installer Teamworks sous Windows
------------------

1. Installez Python 3.7 ou plus depuis le site https://www.python.org. Cochez bien l’option *Add Python 3.x to PATH* durant l’installation.

2. Ouvrez l’invite de commandes de Windows.

3. Placez-vous dans le répertoire d'installation de Teamworks. Exemple :
```bash
cd Teamworks/
```

4. Installez les dépendances avec la commande suivante :
```bash
pip install -r requirements.txt
```

Lancer Teamworks
------------------

Utilisez les commandes suivantes pour vous placer dans le répertoire Teamworks et lancer l'application :
```bash
cd Teamworks/
python Teamworks.py
```
